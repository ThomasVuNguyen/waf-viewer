Scientific Mode

Scientific Mode is Comfy for research, biology, AI, robotics, experiments, datasets, papers, and technical systems. It should feel rigorous, curious, and precise while still being visually warm.

Personality

Curious, rigorous, and experimental.
Precise, but not cold.
Technical, but still understandable.
Evidence-first.
Built for exploration, testing, and learning.

Typography

Use Grandstander for headers and major labels, but keep sizes more controlled.
Use Lora Italic for hypotheses, experiment notes, paper-style callouts, or reflective captions.
Body copy should be highly readable.
Labels, metrics, and data annotations should be short and precise.
UI Style

Dark lab-style background.
Clear panels with strong outlines.
Tables, charts, diagrams, and cards should be clean and scannable.
Use teal for data states, active selections, and scientific signals.
Use gold for discovery, highlights, and “interesting result” moments.
Use coral for anomalies, warnings, or important deltas.
Keep rounded corners and chunky Comfy geometry, but pair it with cleaner information density.
Imagery

Use real research objects whenever possible:
molecules
robots
datasets
model outputs
charts
lab notes
diagrams
screenshots
Avoid generic futuristic science visuals.
Visuals should help explain the experiment, not just decorate it.
Copy Voice
Write like a curious technical builder:

“Hypothesis”
“What we tested”
“What changed”
“What we learned”
“Next experiment”
Keep the tone precise, plain-English, and evidence-backed.

Rule
Scientific Mode should feel like Comfy in the lab: dark, focused, experimental, data-aware, and still warm enough to feel made by humans.
